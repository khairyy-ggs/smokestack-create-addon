# Smokestack (Create addon, NeoForge 1.21.1)

A coal power plant for Create. Coal Boiler -> Steam Turbine -> rotation, with one rule to reason about:
**chimney draft**. Flue Segments stacked directly above a boiler raise its pressure ceiling
(35% with no stack, 100% at 24 segments). The same heat sets coal burn rate, so a tall stack costs fuel.
A full-pressure turbine gives 128 RPM x 128 su = 16384 su, one Creative Motor.

## Status: NOT compiled
The sandbox this was written in could not reach maven.createmod.net / maven.neoforged.net, so the
Minecraft-facing code has never been compiled or launched. APIs were checked against Create's
`mc1.21.1/dev` source. The layout generator (`plant/PlantPlan.java`) is pure Java and was compiled and
checked (see tools/plantcheck). Expect a few compile fixes on first build.

## Getting the .jar
No jar is included: it can only be built where Gradle can download NeoForge and Create.
- **Easiest:** push this folder to a GitHub repo. `.github/workflows/build.yml` builds on every push;
  download `smokestack-jar` from the Actions run (Actions tab, newest run, Artifacts).
- **Locally:** install JDK 21 and Gradle 8.10+, then run `gradle build` in this folder.
  The jar lands in `build/libs/smokestack-0.1.0.jar`. Drop it in `mods/` next to Create 6.0.x
  (and Flywheel / Ponder, which Create ships with) on NeoForge 21.1.x, Minecraft 1.21.1.

## Build
1. Set `create_version` in gradle.properties to a real build from
   https://maven.createmod.net/com/simibubi/create/create-1.21.1/ (6.0.+ is a placeholder).
2. `./gradlew runClient` (add the Gradle wrapper with `gradle wrapper` first).
3. Creative tab "Smokestack".

## Plant Blueprint (creative only)
- Right-click a block: marks the gate; the plant grows away from you.
- Right-click the same block again: builds, ground first, a few ms per tick.
- Sneak + right-click: size 64x48, 100x70, 140x100. Outline and size show while held.
- Built plant: boiler halls, 3-4 rows of boiler + turbine, 24+ segment stacks, cooling towers,
  coal yard + conveyor, office, tank, switchyard, fence. Output shafts leave the east fence.
  Each boiler has a coal barrel + hopper and a water source behind a sight glass.
- Limits: no undo; jobs are lost if the server stops mid-build; needs flat-ish ground.

## Ponder
Hold W over Coal Boiler, Flue Segment, Steam Turbine or Plant Blueprint: 4 scenes.

## Regenerating resources
`python3 tools/gen_assets.py` (pillow, nbtlib) rewrites textures, models, lang, loot, tags, Ponder .nbt.
Textures are generated by script with noise and wear; replace with hand-painted ones when you like.
